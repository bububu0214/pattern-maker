# 紙樣生成器 Pattern Maker

繁體中文介面嘅網頁紙樣生成器：**女裝上衣**同**半截裙**。上傳款式圖或者寫低要求，再按你嘅尺寸出紙樣。

純前端網頁，唔使安裝、唔使上網、唔使伺服器。

## 點樣打開

**電腦：**
1. 喺 GitHub 呢個 repo 揀 branch `claude/womens-pattern-generator-o9bnqa`
2. 撳綠色「Code」→「Download ZIP」，解壓
3. 雙擊 `index.html`，會用瀏覽器（Chrome / Edge / Safari / Firefox）打開

**GitHub Pages（想有網址、用手機開）：**
Repo 嘅 Settings → Pages → Source 揀「Deploy from a branch」→ Branch 揀呢個 branch、資料夾 `/ (root)` → Save。
等一兩分鐘就可以用 `https://<你嘅帳號>.github.io/pattern-maker/` 打開。

## 用法

1. **上傳款式圖（可選）**：揀衫嘅設計圖或者相，可以加幾張（前面、後面、側面、細節），每張揀返係邊個角度
   - **唔使登入**：喺「你嘅要求」寫低想點改，撳「照文字要求改款式」，網頁自己認常用字眼（例如「V領，短袖，衫長45cm，唔要口袋」、「領口開大2cm」、「袖長啲」、「寬鬆」），認唔到嘅會提你
   - 亦可以喺「你嘅要求」寫低想點改（例如「唔要口袋、袖長啲、衫長 65 cm」），AI 會照做，要求優先過相；冇相淨係打字都得
   - 喺 claude.ai 網上版：撳「AI 分析款式」，AI 會認出領口、衫長、下擺、袖、鬆緊度、有冇開胸，自動填好款式
   - 其他情況（例如電腦直接開 `index.html`）：AI 用唔到，可以睇住張圖自己揀款式
2. **款式**（AI 填咗之後都可以改）：
   - 領口：圓領／V 領／方領／一字領，可調領口闊度、前後領深
   - 衫長：短身／及腰／及臀／長身／連身裙長，或者自訂腰下長度／衫總長（後頸點度落下擺）；下擺直腳或 A 字
   - 袖：無袖／短袖／七分袖／長袖（自動按夾圈長度畫袖山，有吃勢同剪口）
   - 鬆緊度：修身（有腰褶）／合身／寬鬆（無褶）——會自動填放鬆量
   - 前中開胸：加門襟同鈕位，可加前貼邊（裁 2 片＋燙朴）
   - 衣領：彼得潘圓領（前後片喺側頸點對齊、肩點重疊 2 cm 畫出，領底線長度同衣身領口一樣）
   - 口袋：左／右／兩邊胸前貼袋（前片會畫埋口袋位）
   - 袖口：袖頭（長袖／七分袖用；袖口有兩個褶同袖衩，另出袖頭紙樣連鈕位同鈕門）
3. **身體尺寸**（厘米）：胸圍、腰圍、臀圍、肩寬、背長、前長、領圍、夾圈、腰至臀、臂長、上臂圍、腕圍
4. **放鬆量**同**縫份**（預設 1 cm），揀前中／後中係咪對摺
5. 撳「生成紙樣」→ 畫面即刻顯示所有紙樣
6. 下載：
   - **PDF（1:1 A4）**：第 1 頁有尺寸表、10 cm 測試方格同拼頁圖；之後每頁一格紙樣，有頁碼（A1、A2…）、對位圓圈記號同框線
   - **SVG**：實際尺寸（cm），分圖層，可以放入 Inkscape / Illustrator
   - **Seamly2D（.sm2d）**：Seamly2D 原生紙樣檔（亦開到 Valentina），詳見下面
   - **DXF**：R12 格式，單位 mm，分圖層（CUT 裁剪線、SEAM 縫線、DART 褶、GRAIN 布紋線、NOTCH 剪口、DIM 尺寸…），可以放入 CAD／紙樣軟件

### 設計細節（通用工具）

上衣：
- 育克：後／前／前後育克，可設深度；育克下可加闊做碎褶或者中間褶（工字褶）
- 公主線：前後各分中片同側片（由夾圈經褶尖落下擺），需要修身或合身
- 泡泡袖（袖山加長收碎褶）、袖口碎褶（燈籠袖）
- 荷葉邊：下擺／袖口／領口，可設闊度同倍數

半截裙亦可以揀碎褶裙、百褶裙（順褶，有摺線同對齊線）、半圓裙、全圓裙。

### 半截裙

「衣物種類」揀「半截裙」：
- 裙型：直身／窄身（鉛筆）／A 字（可設每邊放出）
- 裙長：短裙、及膝、中長、長裙，或者自訂腰下長度
- 開衩：無／後中／前中／側邊，可設長度（紙樣有開衩止點）
- 拉鏈：後中或側邊（紙樣有拉鏈止點）
- 紙樣：前裙片、後裙片（腰褶、臀位弧線、側腰升 0.7 cm、後中腰落 0.6 cm）、腰頭（對摺，連搭位 3 cm，有側、前中、後中剪口）
- 只需要腰圍、臀圍、腰至臀三個尺寸；腰頭長度同裙腰縫線一樣

下擺縫份可以另外設（預設 3 cm），上衣同裙都用。

### 暫時做唔到

褲（製作中）、連身裙（製作中）、其他衣領同外套（製作中）、魚尾裙、分層裙、縮骨、裡布、袋蓋同側袋、不對稱、包身／交叉前襟、後領貼邊。AI 分析時會列出圖入面有呢啲嘅細節。

布料、顏色、印花唔會影響紙樣形狀；如果件衫唔同位置用唔同布（例如袖用牛仔布），AI 會話你邊幾塊紙樣用邊種布裁。

### 用 Seamly2D 開

撳「下載 Seamly2D（.sm2d）」，然後喺 Seamly2D 用「File → Open」開個 `.sm2d` 檔。

- 用 v0.6.0 檔案格式，新舊版 Seamly2D 同 Valentina 都開到；新版開檔時會自動升級格式（可能會問你另存）
- **Draft 模式**：所有點、直線、腰褶、胸圍線，同埋可以拖動修改嘅曲線（領口、夾圈）
- **Piece 模式**：「Back」「Front」，再按款式加「Sleeve」「Collar」「Front facing」「Cuff」「Pocket」紙樣，已設定縫份；對摺邊縫份為 0；夾圈同褶位有剪口；有布紋線同紙樣標籤
- 所有點都由基準點 A 用「角度＋長度」定位，數值固定（未連結量身檔）
- 注意：Seamly2D 唔可以將 DXF／SVG 讀做可以改嘅紙樣，所以要用 .sm2d

### 打印 PDF 注意

- 打印設定揀 **「實際大小」／「100%」**，唔好揀「配合頁面／Fit to page」
- 印完用尺量第 1 頁嘅 10 cm 方格，啱先好剪
- 沿灰色框線剪走一邊頁邊，按頁碼排好，對齊半圓對位記號再貼

## 打版方法（簡述）

- 前片胸寬 = (胸圍 + 放鬆量) ÷ 4 + 0.5；後片 = ÷ 4 − 0.5
- 腰寬同樣分配；胸腰差一部份喺側縫收（每邊最多 2.5 cm），其餘做腰褶
- 領寬會自動調整，令前後領弧總長 = 領圍 ÷ 2
- 夾圈深會自動調整，令前後夾圈總長 = 夾圈尺寸
- 後肩斜 18°、前肩斜 22°；後肩比前肩長 0.5 cm（縮縫）
- 前長比後片長嘅差，用前腰線向下延伸處理

- 側縫用順弧：由夾底收入腰（腰係最窄位），再用臀位弧線（hip curve）出返臀圍，前後側縫長度一樣
- 後中唔對摺嘅修身／合身款：後中喺腰位收入（修身 1 cm、合身 0.6 cm），向上順弧到胸圍線、向下順返出臀
- 衣身長過腰：修身／合身款腰褶變成菱形褶（腰上腰下都收）
- 寬鬆款：無腰褶，側縫直落
- 袖：袖山高按鬆緊度（修身 = 夾圈/4 + 2.5），袖山弧長 = 夾圈 + 吃勢（修身 2 cm、合身 1.5 cm、寬鬆 0.5 cm）；袖剪口位置對返衣身夾圈剪口

呢個係基本紙樣，試身後可以再按身形修改。

## 檔案結構

```
index.html          介面
css/style.css
js/geom.js          幾何工具（曲線、縫份偏移）
js/draft.js         打版計算（衣身、領口、衫長、袖）
js/draft-skirt.js   半截裙打版
js/modify.js        通用設計工具（剪開、加闊、公主線、荷葉邊）
js/layout.js        標示、布紋線、縫份、排版
js/export-svg.js    SVG 輸出（亦用嚟做畫面預覽）
js/export-pdf.js    A4 分頁 PDF 輸出
js/export-dxf.js    DXF 輸出
js/export-seamly.js Seamly2D .sm2d 輸出
js/parse-request.js 唔使 AI 嘅文字要求讀取
js/app.js           介面控制、上傳圖片、AI 分析
```
